# SENSASI – pembungkus PWA (GitHub Pages)
1. Upload SEMUA isi folder ini (termasuk folder `template`) ke repo GitHub baru, mis. `sensasi`.
2. Buka `index.html` di GitHub → ✏️ Edit → ganti `APP_URL` dengan URL Web App (akhiran /exec) → Commit.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Alamat aplikasi: https://NAMA-AKUN.github.io/sensasi/  → isi ke menu Pengaturan → ALAMAT_PWA.
5. Folder `template` dipakai SENSASI untuk mengambil template PDF Induksi & Form APD secara otomatis.
